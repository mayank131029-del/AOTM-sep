Design and build a **modern, premium, responsive multi-page website for a Sustainable Energy project** using the visual direction of a high-end environmental technology website.

The website should feel like a professional portfolio-quality project, not a basic educational/student website.

## Overall Design Direction

Theme: **Sustainable Energy / Clean Technology / Green Future**

Visual style:

* Modern
* Premium
* Clean
* Nature-inspired
* Technology-focused
* Editorial UI
* Strong visual hierarchy
* Subtle micro-interactions
* Smooth animations
* Spacious layouts
* Rounded cards
* Soft shadows
* Large environmental photography
* Data visualization

Use a consistent design system across every page.

### Color Palette

Primary dark green: `#063C2D`
Deep green: `#022A20`
Primary green: `#159447`
Bright green: `#36C978`
Light green: `#DDF5E7`

Solar yellow: `#DDF45A`

Muted text: `#66756F`

Use dark green sections for important visual areas and cream/white sections for content.

### Typography

Use **Sora** for headings and **Poppins** for body text.

Headings should be bold and large with tight line-height.

Use:

* Large 64–80px desktop hero headings
* 40–52px section headings
* 18–20px body text
* Small uppercase labels for categories
* Strong numerical typography for statistics

# RESPONSIVE DESIGN

Design all pages for:

* Desktop: 1440px
* Laptop: 1280px
* Tablet: 768px
* Mobile: 390px

Desktop should use spacious two-column and three-column layouts.

Tablet should reduce columns naturally.

Mobile should use:

* Hamburger navigation
* Single-column cards
* Stacked calculator
* Horizontal scrolling or responsive charts
* Properly scaled typography
* Touch-friendly buttons

Do not simply shrink the desktop layout. Create intentional responsive compositions.
